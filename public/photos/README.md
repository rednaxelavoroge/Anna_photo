# Photos

Grey CoverArt plates on the site are design samples. Put Anna’s selected files here only after she shortlists them. Do not import the old WordPress archive.

```
public/photos/{category}/{album-slug}/01.jpg
public/photos/family/01.jpg              # single-gallery categories
public/photos/backstage/01.jpg
```

Category slugs: `newborn`, `children`, `family`, `individual`, `armenian-costumes`, `underwater`, `smoke-paint`, `seasonal`, `travel`, `commercial`, `reportage`.

Album slugs match `src/data/portfolio.json` (`images-0-1`, `home-discharge`, `babies-1-12`, `sessions`, `animals`, `bloom`, `new-year`, `autumn`, `armenia`, `italy`, `georgia`, `other`, `interiors`, `food`, `watches`, `product`).

Accepted: `.jpg` `.jpeg` `.png` `.webp` `.avif`.
